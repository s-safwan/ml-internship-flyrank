Predictive Content Decay & Editorial Triage at Scale

Lane: Applied Search Intelligence • Dataset: 79M+ Row Warehouse Snapshot • Method: Random Forest Classifier
Abstract: Digital publishers lose significant traffic when mature content decays unnoticed. We investigated whether machine learning could triage decaying web content better than traditional heuristic rules. Using a 79M-row snapshot of GSC and GA4 telemetry, we trained a Random Forest model on physical visibility signals. Validated on a strict 5-fold grouped split, the model achieved a 75.0% accuracy, representing a +4.6% measured lift over heuristic baselines. The resulting artifact is a decision-support playbook that operationalizes these probabilities into a ranked editorial queue for maximum ROI.

1. Problem Framing

Modern organic search performance degrades as query intent evolves and competitors publish updated material. For content teams managing large portfolios, auditing thousands of pages manually is impossible, while simple rules (e.g., "all pages on page 2") create too many false positives. This project builds a quantitative classification model to prioritize high-upside refresh opportunities, saving human editorial time.

2. Data Safety & Scope

We analyzed the March 2026 active-content partition from the FlyRank warehouse. Data is structured at a daily page grain. To ensure rigorous integrity, client_hash_id and content_hash_id were retained exclusively for cross-validation grouping, never as features. Sibling target-leakage columns (like sessions_organic) were strictly excluded from the feature set.

3. Methodology & Baseline

The core objective is a binary classification task: predicting if a page possesses active click-capture potential (has_clicks = True). We established a transparent business heuristic baseline (Impressions > 500 and Position > 10). To prevent memorization and ensure the model learns generalizable principles, validation was conducted using a strict 5-Fold Grouped Cross-Validation (GroupKFold) keyed on the page ID.

4. Results (Model vs. Baseline)

Both models were evaluated on the exact same unseen data splits. The Random Forest model demonstrated superior discrimination capability without relying on domain memorization.

5. Limitations & Honest Framing

  • Intent Blindness: The model evaluates physical visibility (impressions/rank) but cannot parse semantic search intent. High-volume queries with naturally zero CTR will result in false positives.
  • Non-Causal: This is a measured observational pattern for triage decision-support, not a reverse-engineering of Google's causal ranking algorithms.

6. Ranked Recommendations (Action Playbook)

Based on the learned thresholds, pages are dynamically sorted into a 3-tier action queue:

  1. REFRESH_FOR_CTR: High impressions (>1,000) drifting to positions 11–30. Immediate action to optimize meta descriptions and snippet targeting.
  2. EXPAND_CONTENT: Strong rank (Top 10) but low GA4 sessions/scrolls. Action to expand content depth and media.
  3. HOLD: Insufficient visibility or stable baseline performance. Do not touch.

7. Reproducibility

This entire study, including data pipelines and split logic, is fully reproducible. The execution environments, seeds, and notebooks are available in the project repository.
